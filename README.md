# carmelom.github.io

Personal landing page + CV. Static site generated by a small Python
`build.py` that reads YAML/Markdown sources and renders Jinja2 templates.

## Editing content

| Section              | File                              |
| -------------------- | --------------------------------- |
| Bio narrative        | `content/bio.md`                  |
| Education            | `data/education.yaml`             |
| Scientific career    | `data/career.yaml`                |
| Teaching             | `data/teaching.yaml`              |
| Publications         | `data/publications.yaml`          |
| Conferences          | `data/conferences.yaml`           |
| Outreach             | `data/outreach.yaml`              |
| Contact links        | `data/contact.yaml`               |

Every entry has a stable slug `id` used for cross-referencing and for
profile filters.

## Build

```sh
make build        # build the site -> ./site/
make serve        # auto-reloading dev server at http://localhost:9997
make pdf          # build all CV PDFs (use `make pdf-wsl` on Windows)
```

OS-specific notes (Windows / WSL bootstrap, build internals) live in
[`.claude/docs/build.md`](.claude/docs/build.md).

## CV variants (profiles)

Alternate CV outputs (per audience, per application) are defined by
YAML files in `profiles/`. See [`profiles/README.md`](profiles/README.md)
for the schema, filter keys, and build invocation.

## Deployment

GitHub Actions builds the site and publishes via
`actions/deploy-pages`. PDFs are uploaded as workflow artifacts only —
they are not served from the site.

Set the repo's Pages source to **GitHub Actions** (Settings → Pages).
